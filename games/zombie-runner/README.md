# Zombie Runner

Canonical GDevelop source for this experiment lives here.

**Project file (single source of truth):** `games/zombie-runner/zombie-runner.json`

That file is not created in task 001. Task 002 imports the Endless Runner baseline into this path.

When the project exists:

- keep related assets under `games/zombie-runner/` (prefer `assets/`);
- enable GDevelop **multiple-file** save mode so scenes, external events, layouts, and extensions are separate files next to the JSON;
- write generated HTML5/native exports under `export/` (gitignored).

Do not add a second `.json` project in this folder.
