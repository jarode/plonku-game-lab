# 057 — CITY BREAKER playfield world layer

## Goal
Turn the empty playfield into a coherent Plonku city-data world without obscuring gameplay.

## Required implementation
Add restrained layered atmosphere behind/around gameplay:
- subtle technical grid,
- radar/data circles,
- city skyline / infrastructure silhouettes,
- map-like or diagram-like motifs,
- small factor callouts with arrows,
- low-fi/glitch/compression texture,
- original retro utility graphics.

Use the existing city/profile context to label the arena, e.g. city/profile identifier, but do not imply 2012 historical data.

## Rules
- Ball, paddle and collision-relevant objects must remain visually dominant.
- Background cannot reduce readability.
- Decorative elements must not masquerade as real measurements.
- No copied OS/game/product UI.

## Mobile
Simplify/decrease decorative density on narrow screens while preserving identity.

## Evidence
Screenshots: 1440 / 390 / 320 and one active-game frame with ball in motion.

## Acceptance
PASS only if the center of the screen no longer feels empty and the world visually connects the board to a real city/data experiment.
