# 019 — Zombie Runner Wrocław product brief

## Gate

Requires GOAL 003 / task 018 PASS.

## Goal

Turn the proven factory experiment into a real Plonku product target before producing final art or polishing gameplay.

The product is **Zombie Runner — Wrocław**, a short portrait HTML5/mobile runner intended to be usable as a Plonku viral game.

## Scope

Create a concise product brief that locks:

- target player and session length;
- core hook in the first 1–2 seconds;
- Wrocław identity and which city references are allowed/useful;
- player fantasy and zombie tone (fun/viral, not gore-first);
- scoring and fail/retry loop;
- visual direction;
- audio direction;
- mobile-first interaction;
- what makes this materially different from the placeholder runner;
- definition of MVP-ready vs later polish;
- measurable acceptance checklist for tasks 020–025.

Also inspect the current Zombie Runner client and identify which placeholder elements must be replaced or removed for a real product.

## Constraints

- Do not implement the product in this task.
- No paid assets/services.
- Do not broaden into a generic factory redesign.
- Keep the product suitable for Plonku web distribution.

## Acceptance criteria

PASS only if the brief is specific enough that art/gameplay/UI/audio tasks can execute without guessing the product identity, and it lists concrete placeholder debt to remove.

## Result

Create `019_product_brief_zombie_runner_wroclaw-RESULT.md` with the brief, placeholder-debt list, acceptance checklist, limitations, and commit SHA if files change.

## Chain behavior
